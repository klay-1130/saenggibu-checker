# Google Apps Script 배포 안내

## 1. Apps Script 프로젝트 만들기

1. [script.google.com](https://script.google.com)에서 **새 프로젝트**를 만듭니다.
2. 이 폴더의 `Code.gs`, `Index.html`, `appsscript.json` 내용을 각각 같은 이름의 파일로 복사합니다.
3. 프로젝트를 저장합니다.

## 2. 선택: AI 심화 점검 켜기

Apps Script 편집기의 **프로젝트 설정 → 스크립트 속성**에 아래 값을 추가합니다.

| 속성 | 값 |
| --- | --- |
| `OPENAI_API_KEY` | OpenAI API 키 |
| `OPENAI_MODEL` | 선택 사항. 비우면 `gpt-5-mini` 사용 |

API 키는 `Index.html`이나 `Code.gs`에 직접 쓰지 마세요. 키를 설정하지 않아도 기본 기재요령·맞춤법 점검은 작동합니다.

## 3. 웹 앱으로 배포

1. **배포 → 새 배포**를 누릅니다.
2. 유형에서 **웹 앱**을 선택합니다.
3. 실행 사용자는 **나**, 액세스 권한은 사용 목적에 맞게 선택합니다. 학생 기록을 다룬다면 공개 접근보다 조직 또는 지정 사용자만 접근하도록 제한하는 편이 안전합니다.
4. **배포**를 누르고 권한을 승인한 뒤 웹 앱 URL을 사용합니다.

AI 점검 결과는 교사의 기록 검토를 돕는 보조 의견입니다. 학생의 실제 수행 사실을 새로 만들거나 최종 기재를 대신하도록 사용하면 안 됩니다.
