# 생기부 문장 점검 도구

`index.html`을 브라우저에서 열어 사용합니다. 제공된 2026학년도 기재요령 PDF와 점검 예시문 엑셀을 바탕으로 만든, 로컬 전용 문장 점검 페이지입니다.

## 점검 범위

- 공통 금지 표현: 대회, 공인어학시험, 모의고사 성적, MOOC, 방과후학교, 교외·해외 실적, 장학, 특허·출간 등
- 영역별 기준: 자율·동아리·진로·봉사·독서·교과세특·행동특성 및 종합의견
- UTF-8 Byte 기준의 입력 분량과 세특 줄바꿈 여부
- 예시문 기반의 표현·관찰 근거 확인 항목

자동 점검은 보조 수단입니다. 최종 입력은 반드시 교사가 직접 관찰한 사실과 학교의 최신 지침을 기준으로 검토해야 합니다. 입력한 문장은 외부로 전송하거나 저장하지 않습니다.
